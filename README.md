# Richard's Introduction Slide

A visually appealing, single-screen web interface to introduce Richard as a new Software Engineer at Bree.

## Features

- **Header Section**: Name, subtitle, and current role with company
- **Career Timeline**: Visual timeline showing transitions from Edmonton → Vancouver → Bree → Toronto
- **Interests Section**: Hobbies including volleyball, watersports, bouldering, and racket sports
- **Fun Fact**: 536 unique restaurants visited in BC since 2020
- **Cuisine Pie Chart**: Interactive visualization of restaurant cuisine breakdown

## Design

- Single-screen layout (no scrolling required)
- Modern gradient backgrounds and card-based design
- Responsive grid layout optimized for 1920×1080 screenshots
- Clean typography using Inter font
- Colorful icons and visual elements

## Tech Stack

- React 18
- Tailwind CSS
- Vite for build tooling
- Custom SVG pie chart component

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5173`

4. For production build:
   ```bash
   npm run build
   ```

## Customization

To add Richard's photo, replace the placeholder "R" in the header section with an image element pointing to your photo file.

The layout is designed to capture perfectly as a screenshot for presentation purposes.
